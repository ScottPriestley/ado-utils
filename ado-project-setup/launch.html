ADO Migration Launcher

Migrates the process template, area & iteration paths, work items, queries, dashboards, and wiki content from a source project into a target project — in order, with a log.

Open the launcher → Check my setup →

Migration pipeline

  • 01Process
  • 02Default area
  • 03Iterations
  • 04Area paths
  • 05Work items
  • 06Queries
  • 07Dashboards
  • 08Wiki

You choose which steps run. Selected steps always run in this order, and the run stops on first failure.

First time on this PC

  1. Sync the script folders with OneDrive.
  2. Open the synced ADO Migration Launcher folder.
  3. Right-click Setup.cmd → Run as administrator.
  4. Reopen your browser, then use Check my setup.

What you'll need

  • Source project URL + a read-access PAT.
  • Target project URL + a read & write PAT.
  • Collection permission to create a process & a new project.

PATs are used only for the current session — never saved to disk or stored.
